# SBT — Seabuckthorn work, Ladakh

Two pieces of work on seabuckthorn (*Hippophae rhamnoides*) in Ladakh, for
Krishi Vigyan Kendra – Leh under MIDH-SBM.

| | |
| --- | --- |
| [`android/`](android/) | **Seabuckthorn Field Survey – Ladakh** — an offline-first Android app for systematic field survey of seabuckthorn plants: auto-saving survey form, camera, GPS, survey map and CSV/Excel/JSON export. See [`android/README.md`](android/README.md). |
| [`LULC_Seabuckthorn_Classification.js`](LULC_Seabuckthorn_Classification.js) | Google Earth Engine script for land-use/land-cover classification and seabuckthorn mapping. Paste into the [Earth Engine Code Editor](https://code.earthengine.google.com/). |

Developed by Stanzin Khenrab · Krishi Vigyan Kendra – Leh, Ladakh · MIDH-SBM
